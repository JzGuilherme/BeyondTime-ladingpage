📌 Sobre este Repositório (Landing Page)
Este repositório contém o código-fonte da Landing Page oficial do BeyondTime. O objetivo desta aplicação Web é apresentar, promover e demonstrar como funcionará a plataforma BeyondTime para o público 50+ (Silver Economy), investidores e para a banca acadêmica da UNINASSAU.   


A Landing Page destaca a proposta de valor do ecossistema: conexões autênticas por afinidade e hobbies, navegação acessível, segurança por biometria facial com IA e transparência de governança.   

🛠️ Tecnologias da Landing Page
Frontend Web: React 18, Vite, Tailwind CSS, Lucide Icons, Framer Motion.

Tipografia & Acessibilidade: Fontes Roboto (títulos) e Inter (corpo de texto) com tamanho mínimo de 18px para conforto visual.   

Documentação Embarcada: Acesso direto ao documento oficial de governança em PDF (/public/docs/politica-de-governanca.pdf).   


🌐 Visão Geral do Ecossistema Promovido (BeyondTime App)
A Landing Page promove o ecossistema completo do BeyondTime, que contempla:

Aplicativo Mobile: React Native com Expo (SDK 54) e atualizações OTA (expo-updates).

Back-end: Java 21, Spring Boot 3, Hibernate e PostgreSQL.

Segurança & IA: Validação de vivacidade facial (liveness detection/anti-spoofing) e orquestração via Docker.

📌 About this Repository (Landing Page)
This repository contains the source code for the official BeyondTime Landing Page. The purpose of this Web application is to present, promote, and showcase how the BeyondTime platform will work for the 50+ demographic (Silver Economy), stakeholders, and the UNINASSAU academic board.   


The Landing Page highlights the ecosystem's value proposition: authentic affinity connections based on shared hobbies, accessible navigation, AI-driven facial biometrics security, and governance transparency.   


🛠️ Landing Page Tech Stack
Web Frontend: React 18, Vite, Tailwind CSS, Lucide Icons, Framer Motion.

Typography & Accessibility: Roboto (headings) and Inter (body text) fonts with a minimum size of 18px for optimal visual clarity.   


Embedded Documentation: Direct access to the official governance PDF document (/public/docs/politica-de-governanca.pdf).   


🚀 How to Run the Landing Page Locally
Bash
# Clone the repository
git clone [https://github.com/your-username/beyondtime.git](https://github.com/your-username/beyondtime.git)

# Navigate to project folder
cd beyondtime

# Install dependencies
npm install

# Start development server
npm run dev
